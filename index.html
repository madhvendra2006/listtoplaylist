Setup guide

  1. Create a Google Cloud project. In Google Cloud Console, create a project named ListToPlaylist.
  2. Enable YouTube Data API v3. Open APIs & Services → Library, find the API, and enable it.
  3. Create an API key. Under Credentials, create a key, restrict it to YouTube Data API v3, and restrict website use to this page.
  4. Configure the OAuth consent screen. Choose External, enter the app details, and add your Google account as a test user while the app is in testing.
  5. Create an OAuth 2.0 Client ID. Choose Web application. After you deploy the app, add its HTTPS origin under Authorized JavaScript origins—for example, https://yourname.github.io. Use only the scheme and domain, with no page path.
  6. Paste both credentials below. Then select Connect Google. The credentials remain only in this tab and are cleared when it closes.
